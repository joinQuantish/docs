## Feed reference

All feeds update at approximately 1 tick per second. Prices are quoted in USD.

The same seven feed names apply to spot, 30-second TWAP, and 60-second TWAP
events. See [Chainlink TWAP Prices](/crypto/twap) for the August 4 test window,
August 7 cutover, and `twap_windows` filter.

### BTC/USD

Bitcoin. The most liquid and widely traded crypto asset.

```json
{
  "type": "price_feed",
  "feed": "BTC/USD",
  "timestamp": 1774672089,
  "data": {
    "feed": "BTC/USD",
    "price": 66236.61,
    "bid": 66229.77,
    "ask": 66237.94,
    "timestamp": 1774672089
  }
}
```

<Note>BTC/USD has bid/ask spread data. Other feeds currently report bid and ask equal to the mid price.</Note>

## Filtering

Subscribe to specific feeds only:

```json
{
  "action": "subscribe",
  "type": "chainlink",
  "filters": {
    "feeds": ["BTC/USD", "ETH/USD", "SOL/USD"]
  }
}
```

Feed names are case-insensitive. `"btc/usd"` and `"BTC/USD"` both work.

## Subscribing to all feeds

Omit the `feeds` filter:

```json
{"action": "subscribe", "type": "chainlink"}
```

Through August 6, the default stream sends one spot series per feed. Starting
August 7 at 00:00 UTC, it sends both TWAP windows per feed. Select `[30]` or
`[60]` when your application needs only one market-duration mapping.
