Usage packages add capacity to one meter without changing your subscription plan.

| Package | Added capacity | One-time price |
| --- | ---: | ---: |
| **API requests** | 10 million requests | $20 |
| **Order Book + Chainlink** | 100 GB | $20 |
| **On-chain events** | 100 GB | $20 |

You can select from 1 to 100 of one package in a single Checkout. For example, selecting 10 API-request packages adds 100 million requests for a one-time $200 payment.

Packages are resource-specific. Order Book + Chainlink capacity cannot be used for On-chain events, and transfer capacity cannot be used for API requests.

## Purchase and activation

1. Open the [usage dashboard](https://polynode.dev/dashboard/usage).
2. Use the monthly calculator or choose a package directly.
3. Select the quantity.
4. Complete the one-time Stripe Checkout.

Capacity is added only after Stripe confirms a successful payment. Reopening, refreshing, or replaying the same Checkout cannot add the package twice.

The calculator can recommend quantities from your estimate, but it never purchases automatically. Package cost is always shown separately from the recurring plan price.

## Validity and expiration

- Each package remains active for 90 days from purchase.
- Package capacity does not reset at the end of a monthly service period.
- Unused capacity expires after 90 days and does not roll forward beyond that expiration.
- The package with the earliest expiration is consumed first after the included plan allowance.
- The usage dashboard shows each active package, its remaining capacity, and its expiration date.

## Refunds and disputes

A refund or payment dispute removes the unused portion of the related package. Usage already delivered is not erased. If more capacity has been consumed than can be reversed safely, Polynode preserves the usage history and reviews the remaining balance instead of abruptly disconnecting a customer.

<Info>
  Purchasing a package does not replace the existing per-minute, per-second, connection, or Free-session limits documented in [Rate Limits](/guides/rate-limits).
</Info>
