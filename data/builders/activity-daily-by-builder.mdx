---
title: "Builder Daily Activity by Builder"
openapi: "GET /v3/builders/{code}/activity/daily"
description: "Read one builder's daily volume, trades, active traders, trader-paid fees, buy and sell volume, and ranked markets and categories."
---

Read the same daily metrics as the bulk builder activity route for one builder,
plus ranked market and category breakdowns. The response contains exactly one
selected series and does not add `Other`.

```http
GET /v3/builders/{code}/activity/daily
```

## Parameters

| Parameter | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | string | Yes | A `0x`-prefixed, 32-byte builder code. |
| `start_date` | query | string | No | First day, inclusive, in `YYYY-MM-DD` format. |
| `end_date` | query | string | No | Last day, inclusive, in `YYYY-MM-DD` format. |
| `top_limit` | query | integer | No | Ranked markets and categories to return. Default `10`, minimum `1`, maximum `20`. |

Omitting both dates selects the most recent 30 calendar days, including today.
The maximum accepted inclusive range is 366 days. Availability depends on the
requested dates, and an unavailable range returns the generic HTTP `503`
response.

## Example

```bash
curl -H "x-api-key: pn_live_YOUR_KEY" \
  "https://api.polynode.dev/v3/builders/0x4898df15ec6590495dc6c0fedf951ade3e64001d47f9caf44a64e86fc11959df/activity/daily?start_date=2026-08-01&end_date=2026-08-28&top_limit=10"
```

The response uses the [Builder Daily Activity](/data/builders/activity-daily)
envelope. `series` contains exactly one item with `is_other=false`.

The six daily metrics are `volume`, `trades`, `active_traders`,
`trader_paid_fees`, `buy_volume`, and `sell_volume`. Monetary values are
decimal strings with exact `_e6` companions. Ranked market and category rows
cover the complete requested range and omit only `active_traders`.

## Errors

Invalid inputs return HTTP `400` with a stable product error code and message.
An unavailable date range returns HTTP `503`:

```json
{
  "error": "temporarily_unavailable",
  "message": "Builder activity is temporarily unavailable."
}
```
