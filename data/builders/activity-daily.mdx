---
title: "Builder Daily Activity"
openapi: "GET /v3/builders/activity/daily"
description: "Compare daily activity for up to 20 builders with an exact Other series."
---

Compare selected builders across a calendar range. The response returns the
selected builders in request order, followed by `Other`, which aggregates every
builder not selected in the request.

```http
GET /v3/builders/activity/daily
```

## Query parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `builders` | string | Yes | One to 20 comma-separated, 32-byte builder codes. `builder_codes` is an accepted alias. |
| `start_date` | string | No | First day, inclusive, in `YYYY-MM-DD` format. |
| `end_date` | string | No | Last day, inclusive, in `YYYY-MM-DD` format. |

Omitting both dates selects the most recent 30 calendar days, including today.
The API accepts inclusive ranges of up to 366 days, beginning no earlier than
`2020-01-01` and ending no later than today. A requested range that is not yet
available returns the generic temporary-unavailability response described
below.

## Metrics and aggregation

Each `days` row contains six product metrics:

| Metric | Description |
| --- | --- |
| `volume` | Outcome-share par notional attributed to the builder. |
| `trades` | Attributed fill count. |
| `active_traders` | Distinct traders active on that day. |
| `trader_paid_fees` | Fees paid by traders on attributed fills. These are not builder rebates. |
| `buy_volume` | Buy-side outcome-share par notional. |
| `sell_volume` | Sell-side outcome-share par notional. |

Monetary values are decimal strings. Their `_e6` companions contain exact raw
6-decimal units. Bulk responses keep `top_markets` and `top_categories` empty
so comparison cost remains bounded. Use the
[per-builder route](/data/builders/activity-daily-by-builder) for ranked market
and category aggregates over the whole requested range.

`Other` is computed across all non-selected builders. Its daily
`active_traders` value is a distinct count across that complete remainder, not
the sum of per-builder counts.

## Errors

Invalid builder codes, dates, or ranges return HTTP `400`
with a stable product error code and message. A range that cannot currently be
served returns HTTP `503`:

```json
{
  "error": "temporarily_unavailable",
  "message": "Builder activity is temporarily unavailable."
}
```
