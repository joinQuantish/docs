Query multiple wallets at once. Returns the same summary data as the single wallet endpoint, but for up to 100 wallets in one call. All monetary values are in USD.

<OwnerAddresses />

## Request

```
POST /v3/wallets/batch
```

### Request body

```json
{
  "wallets": [
    "0x56687bf447db6ffa42ffe2204a05edaa20f55839",
    "0xa9857c7bcb9bcfafd2c132ab053f34f678610058"
  ]
}
```

| Field | Type | Description |
|-------|------|-------------|
| `wallets` | array | Up to 100 wallet addresses or owner EOAs |

## Example

```bash
curl -X POST https://api.polynode.dev/v3/wallets/batch \
  -H 'Content-Type: application/json' \
  -d '{"wallets":["0x56687bf447db6ffa42ffe2204a05edaa20f55839"]}'
```

## Response fields

Same fields as [Wallet Summary](/data/wallets/summary), with `wallet` instead of `address`. All amounts in USD.

### Owner address fields

Each owner EOA in the request is combined on its own. The response keeps one element per requested address, in request order, and each element's `wallet` stays the address you passed. See [Owner addresses](/data/overview#owner-addresses).

| Field | Type | Description |
|-------|------|-------------|
| `wallets[].wallets` | array | Present only on elements for an owner EOA. The combined wallets, in a fixed order, each `{wallet, type}` with `type` one of `eoa`, `safe`, `proxy`, or `deposit_wallet` |

Totals and counts in a combined element are summed across its wallets.
